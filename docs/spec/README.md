# Official FMI LS-BUS Specifications

This directory contains snapshots of the official **Modelica Association FMI Layered Standard for Network Communication (FMI LS-BUS)** specification:

- `fmi-ls-bus-1.0.0.html`: Official Release v1.0.0
- `fmi-ls-bus-v1.3.0-rc.1.html`: Release Candidate v1.3.0-rc.1
- `fmi-ls-bus-main.html`: Development branch snapshot

Source repository: https://github.com/modelica/fmi-ls-bus
Official documentation: https://fmi-standard.org/fmi-ls-bus/
